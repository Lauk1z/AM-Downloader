1.3.0 加入资料库整理、专辑标签与封面编辑、CUE／SACD ISO 导入，以及每轮不重复的随机播放。

- 在「歌曲／专辑／艺人／最近添加／喜爱的歌曲」标题下按格式、采样率、位深、年份组合筛选；收起的下拉框不会被滚轮误改。点击「查找重复」计算文件 SHA-256，并另外列出同名且时长接近的可能版本，双击查看文件位置，不自动删除。
- 同名专辑按专辑艺人、版本或所在目录区分；CD1／CD2 子目录仍按同一发行版归组。不同编码或母带建议使用独立版本目录，或在编辑窗口设置版本名；相同专辑名、专辑艺人和明确版本名可以合并分组。
- **右键专辑 → 编辑标签与封面**：批量设置专辑、专辑艺人、年份、版本；在表格中编辑歌名、艺人、碟号和曲序；预览并替换封面。主页卡片、专辑页、侧栏专辑和艺人页封面均支持这个入口。普通可写音频通过 Mutagen 写入标签，先完成全部文件的暂存，再替换原文件；原目录保留 `.am-tag-backup-*` 完整备份。音频采样不重编码。CUE、SACD ISO 与不支持标签写入的格式使用本机 `metadata-overrides.json`，原始镜像／整轨保持不变。
- 导入 `.cue` 后按 INDEX 01 显示曲目，支持 UTF-8／UTF-16／中文 CUE 和多个 FILE。有效 CUE 引用的整轨不会额外显示为一首重复音频。逐曲按需生成 PCM 播放缓存，可单曲播放和跳转；没有加入无缝播放或交叉淡化。
- 导入 SACD `.iso` 后读取立体声与多声道曲目；播放当前曲目时使用内置 `sacd_extract` 提取 DSF，DST 使用上游组件解压为 DSD。DSD 数据可继续使用共享解码、ASIO 原生或 DoP 输出。首次准备曲目需要时间，缓存可在「设置 → 清理播放缓存」中清理。普通数据 ISO 不会当作音频导入。整轨／镜像内曲目的右键只允许从列表删除，避免误删整张专辑。
- 随机播放使用洗牌轮次：当前播放范围内每首歌每轮一次，多首歌曲时下一轮首曲也避开上一轮末曲；「上一首」沿播放历史返回，再次前进沿原历史继续。主动重新选择播放范围或切换随机开关会开始新轮次。

验证涵盖合成 CUE 与 SACD 镜像、提取后的数字样本、标签往返和界面流程；没有使用真实商业 SACD／DST 镜像或 DAC 硬件完成本版验收，详见 TEST_REPORT.md。

1.2.21 加入 Windows 原生音频输出：在「设置 → 音频输出」选择设备和模式，点击「应用音频设置」即可生效并记住选择。WASAPI 独占支持 PCM／DoP；ASIO 支持 PCM／DoP／原生 DSD。播放状态显示驱动协商的实际输出格式，源文件的 DSD 标签不再代替输出方式。

SMSL DAC 可选择「ASIO → USB DAC ASIO → 原生 DSD」。连接设备的厂商驱动报告支持 DSD64／128／256／512，已用合成数字静音实际验证四个档位的输出、暂停、恢复和时长。DSD512 以 22.5792 MHz 传输；DoP 的最高档位另受 DAC 的 DoP 和 PCM 传输能力限制。软件默认保留原共享模式，应用音频设置后才启用所选直通方式。

直通模式旁路软件音量，不添加均衡、重采样或混音，请用 DAC 调节音量。选择不支持的格式、设备断开或驱动被占用时停止并提示，不静默回退。DSD 直通目前支持 DSF、未压缩 DFF／DSDIFF；DST、WavPack DSD 保留共享模式解码。共享模式继续支持原有全部音频格式；SACD ISO／CUE 在 1.3.0 新增，详见本页开头。暂停保持当前位置，跳转重新建立输出并清空旧缓冲；重启恢复设备与最后一首歌曲，但不自动播放或占用 DAC。

音频引擎在独立 Windows 进程中运行，原生线程和预分配缓冲供给 WASAPI／ASIO，Python 只负责控制和进度。源码及构建方法在 `source/native` 和 `source/build_audio.py`，使用 Windows SDK 与 ASIO SDK 的 GPLv3 版本，没有捆绑 BASS 或 foobar 插件。测试范围与实际限制见 TEST_REPORT.md。

1.2.16 扩展本地音频导入与播放，新增 DSF、DFF/DSDIFF、AIFF/AIFC、APE、WavPack、TAK、TTA、WMA、Musepack、OGA、Speex、MP2、AC-3/E-AC-3 等格式及扩展名别名。支持多选、文件夹递归扫描和拖入；继续直接播放原文件，不先整首转码，不修改原音频。

OGG 按实际编码区分 Vorbis、Opus 和 FLAC，并修复 FLAC/OGG 元数据读取被 MP4 标签名阻断的问题。DSF/DFF 读取歌名、艺人和内嵌封面，音质显示 DSD 倍率及真实 MHz 采样率；DSD WavPack 读取块内倍率，避免误报为 PCM 采样率。压缩 AIFC、压缩 WAV、WavPack Hybrid 不误标无损，未知位深不假定为 16 bit。

**1.2.16 的 DSD 播放方式（1.2.21 起保留为共享模式）：**使用内置 Qt/FFmpeg 实时解码为浮点 PCM，再由系统音频设备输出。该模式的实际输出格式受系统混音器和音频设备影响。新增直通方式见本页 1.2.21 说明。无需安装 foobar2000 或额外解码包。

检查了 [foo_input_sacd 2.0.25 源码](https://sourceforge.net/projects/sacddecoder/files/foo_input_sacd/)。其 libdsdpcm 可单独适配；插件接口及输出层依赖 foobar2000 SDK，不能直接加载 .fb2k-component。本程序没有捆绑或移植该插件；1.2.21 的原生 DSD／DoP 使用单独实现的 Windows 输出通道。

支持列表以当前内置解码器为准，不承诺所有容器变体、DRM 文件和损坏音频。DSD64/128/256 的 DSF/DFF、OGG 三种编码和多种 PCM 格式已用合成音频逐项测试；详细覆盖范围及限制见 TEST_REPORT.md。

1.2.15 完善启动时恢复账号：内置后端确认上次登录仍有效后，直接沿用并显示「已登录」，无需重复输入账号密码。需要重新认证时，使用上次成功账号已加密保存的密码自动登录一次；需要双重认证时仍显示验证码窗口。新账号登录默认勾选「记住密码」和「自动登录」，可以取消；历史账号保留其已有选择。未保存密码且原登录状态已失效时，需要手动补充密码。

登录失败不会循环尝试；错误密码或验证码修正成功后，按窗口中勾选的选项保存，保留后续自动登录能力。未确认登录状态时显示「未登录」，不把账号历史当作成功登录证明。

1.2.14 改善主页专辑右上角标识的可读性：按标识所在位置实际显示的封面颜色，自动选择黑色或白色图标与文字；明暗交错、花纹复杂时增加小范围的半透明圆角底衬。适配封面裁切和高 DPI，悬停时保持颜色稳定，计算结果缓存复用，不修改封面文件。

1.2.13 修复验证码窗口提前关闭：验证码错误、过期、超时或连接中断时，在原窗口显示原因，只有后端明确确认登录成功才自动关闭。若本次验证连接已结束，点击「重新验证」重新请求验证码，再在原窗口输入；不会自动重复提交账号密码或旧验证码。也可以手动取消验证，返回账号密码界面。重复验证码提示复用原窗口，旧请求的迟到结果不会影响新的验证。

1.2.12 完善账号登录：只有后端明确确认成功后才自动关闭窗口，账号、密码或验证码错误时保留界面供修改重试。点击账号输入栏可展开成功登录过的账号，选择历史只填账号，不填密码。勾选「记住密码」后，在登录成功时使用 Windows 当前用户的 DPAPI 加密保存；再次打开登录窗口可恢复上次账号的已记住密码，取消勾选会清除保存的密码。

「自动登录」需勾选记住密码，仅用于内置后端：启动后已有登录状态时直接沿用，无登录状态时才尝试一次；失败停止自动尝试并保留登录窗口。Apple 要求双重认证时仍显示独立验证码窗口。验证码必须是六位数字，不保存；取消、超时和连接中断均释放登录锁，可再次登录。自动登录不能跳过 Apple 的验证要求。

1.2.11 专注后端启动：保留虚拟机原有 Linux 内核，为当前账号镜像生成独立、带 SHA-256 校验的直接引导缓存。优化根文件系统探测，在 IPv4 地址和默认路由就绪后让 IPv6 地址检测继续后台进行。首次启动准备缓存，之后自动使用快速引导；文件损坏使用原引导并重新准备，快速引导实际失败会回退且暂停再次尝试，取消启动不会触发重启。已有手动硬件加速配置保留，无 WHPX 时也支持兼容模式。

缓存位于运行数据目录的 `backend/boot`，不写入安装包；镜像更换或内核变化时重新校验。没有替换虚拟机磁盘上的内核、关闭 IPv6 或更改账号登录内容。实测结果和适用范围见 TEST_REPORT.md。

## 运行

将 ZIP 中整个 `AM Dowloader` 文件夹解压到任意可读位置，双击 `AM Dowloader.exe`。例如：

`D:\Apps\AM Dowloader\AM Dowloader.exe`

从旧版升级可沿用 `MusicDesk` 安装目录；本机更新后的入口为 `D:\AppleMusicDecrypt-Windows\MusicDesk\AM Dowloader.exe`，桌面快捷方式为「AM Dowloader」。

保留旁边的 `_internal` 和 `backend` 文件夹，不能只复制 EXE。支持 Windows x64。无需管理员权限、开启虚拟化或另外安装 QEMU；默认使用软件模拟。程序包和首次初始化的用户数据合计约需 1.7 GB 空间，另需为音乐预留容量。

首次使用：打开「设置」→「登录 Apple 账号」，完成密码与双重认证；再点击「添加音乐」粘贴 Apple Music 链接。账号需具备所选地区歌曲的访问权限和有效的 Apple Music 订阅。旧版用户的资料库、收藏与界面偏好保留，内置服务使用独立账号环境，首次需重新登录。

## 使用

- **本地音乐**：新用户默认使用 Windows「音乐」文件夹中的 `AM Dowloader`。升级保留已有资料库，设置中可选择其他文件夹。歌曲与封面来自实际文件。
- **导入音频**：「添加音乐」→「导入本地音频」，或按 `Ctrl+O` 多选文件，也可直接拖入窗口。「导入文件夹」会在后台扫描文件夹及子文件夹，批量导入并去重。支持 M4A、MP3、FLAC、WAV、AAC、Opus、OGG。导入只记录原文件位置，不复制或移动文件；文件被移动后需重新导入。
- **播放器**：顶部左侧为随机、上一首、播放/暂停、下一首、循环按钮，中间显示封面和当前歌曲，歌曲信息下方为进度条；右侧控制音量、歌词及队列。悬停在歌曲区域查看真实音质，悬停进度条查看时间。
- **恢复歌曲**：重新打开软件时选中上次关闭前的歌曲，不自动播放；若原文件已删除或无法读取，保留空播放器，不会影响资料库使用。
- **删除音乐**：在歌曲列表中右击，选择「从列表中删除」或「删除本地文件」。列表移除同时清理该曲的收藏、最近播放与导入记录，音频保留在原位置；删除本地文件使用系统回收站，失败时保留资料库记录并提示原因，不会退回永久删除。
- **搜索曲库**：通过内置后端查找中国区 Apple Music 歌曲及封面，打开歌曲详情后加入下载队列。可下载性由账号地区、订阅及曲目音源决定。
- **添加音乐**：粘贴歌曲、专辑、歌单或艺人链接，可一次粘贴多条。选择 ALAC、AAC 等音质后加入队列。也可把链接拖入窗口。无需输入 `dl` 命令。
- **下载队列**：按顺序运行链接任务，显示曲目数量、下载/解密阶段与速度。可以取消、重试、暂停后续任务、清除已完成任务。关闭后再次打开时，未完成任务保留，点击「继续队列」恢复。取消不会删除已保存的歌曲。
- **设置**：默认音质、元数据语言、采样率和位深上限。保存时只改对应配置项，原配置自动备份为 `config.musicdesk-backup-时间戳.toml`。
- **账号**：通过内置本地服务登录，支持密码与双重认证。界面不把密码写入偏好文件；后端会在当前用户的私有镜像中保存登录会话。

点击「暂停队列」会让当前任务继续完成；立即停止当前任务请点击该行的「取消」。下载音质受曲目音源、账号、地区及配置的回退策略影响，播放器显示文件实际编码/位深/采样率。歌词侧栏读取已有 LRC 文件，按时间高亮当前行并滚动定位；点击带时间轴的歌词可跳转到该句开头。

图形界面在本次进程中启用严格完整性检查；解码校验失败会显示任务失败，避免把坏文件当作完成。此项不会更改原命令行配置。

内置服务使用独立的本机端口，与原命令行下载器互不占用账号镜像。正常退出请求服务关机，工作进程异常退出时 Windows 会清理它的子进程。原下载器和原账号不被修改。

## 数据与排错

界面偏好、收藏、队列、导入记录、上次歌曲和封面缓存保存在 `%LOCALAPPDATA%\MusicDesk`，内置后端配置及账号镜像在其中的 `backend` 文件夹。沿用旧数据目录名称以兼容升级。安装包内的镜像是经过校验的初始镜像，不含本机账号或音乐。

「音乐资料库」同时作为内置下载的保存根目录和扫描目录，普通歌曲按「专辑艺人 / 专辑」归档，歌单按「playlists / 歌单名称」归档。切换目录影响后续任务，不搬动已经保存的音乐。

下载失败时查看队列下方日志，悬停任务行可查看完整错误。后端状态异常可先取消任务，再在设置中「重新连接后端」。可从队列导出诊断日志，导出时隐藏常见令牌、账号与 URL。启动失败可查看用户数据目录 `backend\qemu.log`。

在线搜索与下载需要网络，首次登录后端可能需要几十秒。窗口退出时会等待后端清理，最长约 25 秒。

快捷键：`Ctrl+L` 添加音乐；`Ctrl+O` 导入本地音频；`Ctrl+F` 搜索；`Ctrl+←/→` 前后曲。

## 从源码构建

Windows x64、Python 3.12：

```powershell
python -m venv .build-venv
.\.build-venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.build-venv\Scripts\python.exe build.py
.\.build-venv\Scripts\python.exe package_release.py
```

生成目录：`dist\AM Dowloader`。运行源码：

```powershell
.\.build-venv\Scripts\python.exe build_backend.py
.\.build-venv\Scripts\python.exe MusicDesk.py
```

普通测试：`python -m pytest tests -q`。`test_gui.py` 中针对现有歌曲的测试需要本机 `D:\AppleMusicDecrypt-Windows` 测试资料库。`live_gui.py` 和 `live_backend.py` 是手动运行的网络集成检查，后者要求显式指定独立输出目录，不会修改原配置。

构建脚本下载并校验固定版本的上游 Windows 运行包，网络不可用时可使用 `vendor\v2-clean.zip` 缓存。内置源码固定于 v2 提交 `d1a9a10079a72a454ce013589a5a47d5c17c8aee`；Windows 路径兼容补丁记录在 `backend\PATCHES.md`，构建不跟随上游分支自动变化。

包内 `source` 提供界面、桥接与构建代码；`backend\src` 提供实际运行的下载器源码。许可证与组件来源见 `LICENSE.txt`、`THIRD_PARTY_NOTICES.md`。开发调试可显式使用 `--backend-root 路径` 连接旧下载器；此模式沿用旧后端配置，普通用户无需设置。
