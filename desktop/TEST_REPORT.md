## 1.2.11 Linux 启动链路优化

## 复验

源码中的 `tests/live_backend.py` 可指定独立输出目录，执行下载后读取媒体参数并用 FFmpeg 完整解码。`tests/live_gui.py` 验证在线界面流程。EXE 的开发验证入口：

```powershell
.\MusicDesk.exe --backend-root D:\AppleMusicDecrypt-Windows --data-dir C:\Temp\MusicDesk-test --smoke-test C:\Temp\MusicDesk-check
```

该入口会静音播放现有歌曲，搜索 Eagles，调用已有歌曲检查，并将报告及截图写到指定目录；不会在正常启动时运行。

`--ui-smoke-test C:\Temp\MusicDesk-ui-check` 只运行本地播放及侧栏动画检查，不连接下载后端。

`--animation-benchmark C:\Temp\MusicDesk-animation-check` 在最大化窗口依次切换七个页面，记录完成帧数、帧间隔中位数/P95/最大值和切页同步耗时；不会连接下载后端。帧率结果仅代表测试机器、显示器和当前负载。

实现依据：[Qt QOpenGLWidget 绘制与帧交换说明](https://doc.qt.io/qt-6/qopenglwidget.html)。
