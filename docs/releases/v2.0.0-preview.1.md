# AM Downloader 2.0.0-preview.1 · 原生 WinUI 3 大升级

这次是应用框架重构：从 Qt / PySide6 桌面应用迁移到 **C# + WinUI 3 + Windows Composition**，在新框架中重建窗口、页面、动画和应用控制层，沿用现有的布局、使用习惯、资料库格式和下载、音频核心。

本次发布为 **Pre-release（预览版）**，1.5.2 继续作为稳定版。新版已完成自动化与独立发布包验收，但真实 Apple 账号和 DAC 播放尚未完成全项复测；下方列出具体边界。

## 1. 原生 Windows 应用层

- 主窗口、集成窗口控制按钮、侧栏导航、主页、艺人、专辑、歌曲、收藏、搜索、设置与弹窗迁移到 WinUI 3。
- 播放控制、歌词与正在播放侧栏、下载队列、账号窗口、系统托盘、关闭选择和单实例唤回迁移到 C#。
- 深色与玫瑰红主题、专辑模糊背景和 Composition 动画沿用原设计。
- 新 EXE **不加载 Qt、PySide6 或 Qt Multimedia**。音频继续由 C++ 原生主机处理；标签、封面和 CUE / SACD 准备使用独立的无 Qt Python 工具进程；在线下载继续使用内置 AppleMusicDecrypt 后端。并非将解码器、虚拟机或下载引擎改写成 WinUI。
- 提供自包含 x64 发布包，内带 .NET 和 Windows App SDK 运行时。

| 专辑与艺人 | 主页精选与最近播放；艺人双栏浏览；专辑在主内容区展开；标签和封面批量编辑、原文件备份与虚拟曲目覆盖信息 |
| 歌单与队列 | 自定义歌单的新建、重命名、删除、拖入和排序；M3U / M3U8 导入导出；独立的正在播放队列、下一首 / 最后播放、排序、移除、保存与恢复 |
| 播放习惯 | 每轮不重复的洗牌随机；自然切歌保留 **2 秒间隔**，手动切歌即时响应；重启恢复最后歌曲与队列，但不自动播放 |
| 歌词 | 加粗歌词、LRC 时间轴和同时间翻译分组；平滑跟随；点击歌词跳转；右侧展开与收起 |

| 窗口与托盘 | 收起后继续工作；重复启动恢复原窗口；关闭时选择托盘或退出并可记住；托盘菜单退出执行正常关闭流程 |

## 3. 本次集中修复

### 页面、导航与封面

- 普通切页复用侧栏按钮及四张已解码封面，避免反复清空重建导致闪现。
- 选中红条加入连续位置过渡，快速连续切换可从当前动画位置衔接。
- 调整切页的整页淡入，保留其他场景仍需使用的动画。
- 主页和专辑页滚动容器延伸至主内容区右侧，内容保留安全留白；不额外包裹 GridView，保留其滚动与虚拟化。
- 精选卡片先获取处理后的封面、等待解码并协调标识配色，再首次显示；复用缓存，避免先露出原图再切成蒙版图。
- 保持专辑模糊背景，整理歌词展开、收起及不同宽度下的布局。

### 统一主题与音量条

- 下载链接弹窗、退出确认、主要按钮、文本框焦点与选择、复选框及下拉选中状态统一为应用玫瑰红 **#FF3565**。
- 主要按钮在默认、悬停、按下状态保留白色文字，修复残留的系统浅蓝强调色。
- 音量区采用左右等宽图标和一致间距，修复轨道两端不对称；独占输出仍旁路软件音量。

### DSD 能力检测与输出切换

- 检测前正常释放播放器持有的设备，不再仅因“已暂停但主机仍占用设备”要求反复切回兼容模式。
- 串行处理停止、打开、设置应用和能力查询，等待旧主机结束，避免软件自身抢占设备。
- 查询保留当前曲目和进度，结束后保持暂停；准备曲目期间触发查询也不会意外开始播放。
- 等待音频主机报告就绪后才确认应用成功；失败时恢复此前配置，不保存无效的新设置。
- ASIO 不再默认选中列表第一项 Realtek；需明确选择 DAC 对应的驱动，刷新设备或切换模式时保留有效选择。
- 驱动初始化错误显示具体驱动名称和原因，避免将所有失败都归为笼统的“设备断开或忙”。这不保证故障或不兼容的驱动可以使用。

## 4. 下载、运行与迁移

**系统：Windows 10 2004（19041）及更新版本，x64。**

1. 下载附件 **`AM-Downloader-2.0.0-preview.1-WinUI3-Windows-x64.zip`**。约 **442 MiB**，完整解压约 **842 MiB**；它是便携包，不是安装程序。
2. 解压到新文件夹，保留全部文件与子目录，运行 **`AM Downloader WinUI.exe`**。GitHub 自动生成的 Source code ZIP 只有源码，不能直接使用。
3. 从旧版迁移前，先在托盘菜单正常退出旧版。新版默认沿用 `%LOCALAPPDATA%\MusicDesk`，兼容资料库路径、收藏、歌单、队列、最后歌曲和同一 Windows 用户的 DPAPI 账号信息，首次写入前备份原偏好文件。建议先自行备份重要数据。
4. 需要独立试用时：`& '.\AM Downloader WinUI.exe' --data-dir 'D:\AM-WinUI-Test'`。避免两个版本同时写同一份数据。
5. 不必另装 Python 或 .NET SDK；ASIO 需自行安装 DAC 对应的 64 位驱动。在线后端首次初始化需要额外时间和磁盘空间，账号镜像与音乐不计入包体积。

发布 ZIP 与本机已更新并验收的 r5 构建一致，仅调整对外下载文件名。保留 1.5.2 稳定版，ZIP 不自动卸载或覆盖原安装。

## 5. 已验证范围与待验收项目

- **126 项核心断言通过**：状态保存、队列、洗牌、曲间间隔、歌词、M3U 和格式显示。
- **26 项引擎测试通过**：18 种生成音频与 FFmpeg 参考解码比较、DSD64–512 / DoP 字节与定位、CUE / SACD、标签事务与配置保留。
- **4 项音频服务回归通过**：失败设置回滚、并发停止等待释放、暂停与重复查询恢复、准备期间不意外播放。
- **正式发布 EXE 的 25 项检查通过**：11 个页面，以及主题、导航、布局、模拟登录、生命周期和静音虚拟端点播放等；在仓库外全新解压，核对 **4,409 个文件**、本地运行时与应用资源。
- 主页和专辑页检查 1100 / 1440 / 1800 请求窗口宽度与底部滚动；主题检查主要按钮默认 / 悬停 / 按下状态；音量轨道检查左右间距。
- 本机 **USB DAC ASIO** 连续三次查询报告 DSD64 / 128 / 256 / 512；**Realtek ASIO** 在没有播放主机时仍初始化失败，已改为明确报告所选驱动。这些是驱动查询结果，**不是实际 DSD512 播放验收**。

仍需实机验收：真实 Apple 账号首次登录、二次认证及在线下载；DAC 的 WASAPI / ASIO PCM、DoP、原生 DSD 播放；真实 APE / TAK / Musepack / DST 样本和大型资料库；鼠标拖放及高刷新率下的动画体验。本次不宣称固定帧率、全设备兼容或硬件输出已全面复测。

源码位于 [`desktop/winui`](https://github.com/Lauk1z/AM-Downloader/tree/v2.0.0-preview.1/desktop/winui)，验证矩阵见其中的 `MIGRATION.md`；原 Qt 源码和上游 Fork 历史继续保留。
