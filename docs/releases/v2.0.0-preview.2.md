# AM Downloader 2.0.0-preview.2 · 圆润图标更新

这次为原生 **WinUI 3** 版本统一重绘程序内图标，采用圆润、饱满的轮廓，与深色界面及玫瑰红主题保持一致。此版本为 **Pre-release（预览版）**，1.5.2 继续作为稳定版。

## 本次更新

- 重绘 **28 组自绘图标**，覆盖播放／暂停、上一首／下一首、随机／循环、音量、无损标识、歌词、队列，以及主页、艺人、专辑、歌曲、收藏、下载、歌单、资料库、设置等入口。
- 统一图标比例、描边、圆角与端点；播放控制和音符采用更饱满的实心形状，改善小尺寸下的辨识度。
- 按钮、导航标题、收藏标记和空封面中的文字符号改为统一的矢量图形，减少字体不同带来的外观差异。
- 图标跟随按钮的文字颜色及交互状态，禁用时降低透明度；补充图标按钮的无障碍名称。
- 保留已经确认的玫瑰红应用 Logo、页面布局和操作逻辑。此次未修改音频解码、输出链路、下载后端或账号行为。

## 下载与升级

1. 下载附件 **`AM-Downloader-2.0.0-preview.2-WinUI3-Windows-x64.zip`**，约 **442 MiB**；完整解压约 **842 MiB**。这是便携包，不是安装器。
2. 在系统托盘中正常退出旧版，完整解压到新文件夹，运行 **`AM Downloader WinUI.exe`**。请保留全部子目录，不要只替换 EXE。
3. 新版沿用 `%LOCALAPPDATA%\MusicDesk`，保留现有资料库、收藏、歌单、队列及账号设置。请避免同时运行新旧版本。
4. 系统要求仍为 **Windows 10 2004（19041）及更新版本，x64**，内含 .NET 和 Windows App SDK 运行时。

附件提供 `SHA256SUMS.txt` 和逐文件 `manifest.sha256.json`；ZIP 内也包含清单、对应源码与第三方组件声明。

- WinUI Debug 与 Release 构建通过：**0 警告、0 错误**。
