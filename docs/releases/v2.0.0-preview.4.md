# AM Downloader 2.0.0-preview.4 · 托盘菜单焕新与自动收起修复

本次更新将托盘右键菜单改为与应用匹配的深灰圆角样式，并修复点击桌面、任务栏等菜单外空白区域后，菜单可能一直停留的问题。同时包含此前加入的三种歌词显示模式设置。此版本为 **Pre-release（预览版）**；**1.5.2 继续作为稳定版**。

## 本次更新

### 托盘菜单样式

- 使用原生 WinUI 3 菜单窗口，替换旧式系统弹出菜单；采用深灰背景、圆角外框、细分隔线和紧凑行距。
- 统一悬停、按下和禁用状态；当前歌曲信息使用较淡文字，过长时显示省略号。
- 保留显示主窗口、播放／暂停、上一首、下一首、正在播放队列、音频输出链路、最小化到托盘及退出操作。
- 支持方向键、Home／End 和 Esc；无可播放歌曲时禁用对应操作。菜单按显示器工作区定位，主窗口收起时打开菜单不会同时唤出主窗口。

![新版深灰圆角托盘菜单，来自正式修复包的原生渲染](https://raw.githubusercontent.com/Lauk1z/AM-Downloader/v2.0.0-preview.4/docs/screenshots/winui-tray-menu.png)

### 点击空白处自动隐藏

- 菜单显示期间补充外部鼠标按下检测，不再只依赖窗口失焦事件；点击菜单外部时自动收起，覆盖没有触发失焦的空白区域。
- 保留菜单内部按钮点击及外部点击原有的作用，不吞掉鼠标事件。
- 菜单关闭后立即移除临时鼠标监听；重复右击、连续外部点击或失焦与点击同时发生时，避免重复关闭旧窗口。

### 歌词显示模式

在「设置 → 歌词显示模式」中选择，切换立即生效并保存：

- **浮动**：逐字高亮，已播放文字轻微浮起。
- **逐字高亮**：按句内进度变亮，文字不浮动。
- **普通**：当前整句高亮，保留最初的歌词呈现方式。

三个模式均保留上下渐隐、平滑滚动和点击歌词跳转。普通 LRC 的逐字进度仍按句内时间估算；有增强 LRC 时间标记时按标记同步。

## 下载与升级

需要 **Windows 10 2004（19041）或更新版本、x64**。安装版和便携版使用同一套已验证运行文件，内含 .NET、Windows App SDK、音频引擎及下载后端。

| 附件 | 用途 | 大小 |
| --- | --- | --- |
| `AM-Downloader-2.0.0-preview.4-WinUI3-Windows-x64-Setup.exe` | 安装版，支持选择目录、快捷方式和卸载 | 392,514,770 字节，约 374 MiB |
| `AM-Downloader-2.0.0-preview.4-WinUI3-Windows-x64.zip` | 便携版，完整解压后运行 `AM Downloader WinUI.exe` | 463,882,638 字节，约 442 MiB |
| `manifest.sha256.json` | 运行目录逐文件 SHA-256 清单 | 与 ZIP 内清单相同 |
| `SHA256SUMS.txt` | 安装包、ZIP 与清单的 SHA-256 | 用于下载核对 |

升级前请在**系统托盘菜单选择「退出」**，再运行安装器或将便携版解压到新目录。安装版默认安装到 `%LOCALAPPDATA%\Programs\AM Downloader`，无需管理员权限；安装器尚未进行代码签名。

继续使用 `%LOCALAPPDATA%\MusicDesk`，保留资料库路径、收藏、歌单、播放队列及同一 Windows 用户的账号设置。卸载保留个人资料库和原音乐文件；请避免新旧版本同时运行。
