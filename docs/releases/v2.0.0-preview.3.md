# AM Downloader 2.0.0-preview.3 · 列表高亮修复与逐字歌词

本次更新修复多个歌曲列表中高亮背景与圆角叠加的问题，为歌词加入上下渐隐、句内逐字高亮和轻微浮起效果，并首次提供 Windows 安装版。此版本为 **Pre-release（预览版）**；**1.5.2 继续作为稳定版**。

## 本次更新

### 歌曲列表与交互

- 歌曲、最近添加、喜爱歌曲、搜索、专辑详情和自定义歌单共用一层圆角高亮，避免系统选中背景与自绘背景叠出边框、错位和大小不一致的圆角。
- 保留隔行背景、悬停／按下／选中状态、键盘与多选操作、拖入歌单和歌单排序；滚动复用列表容器时重置指针状态，避免高亮残留。
- 包含 preview.2 之后的相关交互修复：艺人页歌曲悬停高亮、歌曲菜单锚定到右侧「…」按钮，以及全局快捷键产生的孤立 `Ctrl+L` 提示。

![单层圆角歌曲高亮，使用隔离测试资料库渲染](https://raw.githubusercontent.com/Lauk1z/AM-Downloader/v2.0.0-preview.3/docs/screenshots/winui-song-highlight.png)

### 歌词效果

- 歌词侧栏顶部和底部加入透明度渐隐，文字滚入／滚出边缘时逐渐显现或消失。
- 当前句按播放进度逐字变亮、轻微向上浮起；已播放的字保持抬起，未播放的字保持原位。保留加粗字体、自动居中滚动和点击跳转。
- 暂停时停住句内进度；回退、跳转和换行时同步更新高亮及位移，避免上一段动画残留。
- 优先使用增强 LRC 的 `<mm:ss.xx>` 时间标记；同一时刻的原文与译文并行推进，并按 Unicode 字素处理组合重音和表情。
- **普通 LRC 只有整句时间戳时，逐字进度按句内时间估算，并非音频识别或精确演唱对齐。**实际效果取决于歌词文件提供的时间数据。
- 句内动画使用 Windows Composition 的合成动画，避免每帧重建文字布局；本次没有声称或测得固定动画帧率。

![逐字明暗和浮起效果的静态示例，使用生成的歌词渲染](https://raw.githubusercontent.com/Lauk1z/AM-Downloader/v2.0.0-preview.3/docs/screenshots/winui-lyrics.png)

## 下载与安装

需要 **Windows 10 2004（19041）或更新版本、x64**。两种分发方式使用同一套运行文件，内含 .NET、Windows App SDK、音频引擎和下载后端。

| 附件 | 用途 | 大小 |
| --- | --- | --- |
| `AM-Downloader-2.0.0-preview.3-WinUI3-Windows-x64-Setup.exe` | 安装版，支持目录选择、快捷方式和卸载 | 392,513,248 字节，约 374 MiB |
| `AM-Downloader-2.0.0-preview.3-WinUI3-Windows-x64.zip` | 便携版，完整解压后运行 `AM Downloader WinUI.exe` | 463,894,837 字节，约 442 MiB |
| `manifest.sha256.json` | 运行目录逐文件 SHA-256 清单 | 与 ZIP 内清单相同 |
| `SHA256SUMS.txt` | 安装包、ZIP 与清单的 SHA-256 | 用于下载核对 |

1. 升级前在**系统托盘菜单选择「退出」**，关闭旧版；仅关闭窗口可能仍在托盘运行。
2. 安装版默认安装到 `%LOCALAPPDATA%\Programs\AM Downloader`，不要求管理员权限，也可选择其他可写目录。开始菜单提供启动入口，桌面快捷方式可选；安装器尚未进行代码签名。
3. 便携版请完整解压到新文件夹并保留全部子目录，不要只替换 EXE。解压后的运行文件约 842 MiB，音乐、账号镜像和播放缓存另占空间。
4. 继续使用 `%LOCALAPPDATA%\MusicDesk`，保留资料库路径、收藏、歌单、队列和同一 Windows 用户的账号设置。安装器不卸载旧 Qt 版；卸载 WinUI 安装版保留个人数据和原音乐文件。
5. 请避免同时运行新旧版本；源码归档不包含可直接使用的完整安装环境。

## 验证与边界

- **132 项核心断言通过**，覆盖歌词时间解析、增强 LRC、偏移、重复时间戳、翻译和 Unicode 字素，以及原有状态、队列、洗牌、间隔、M3U 和格式显示。
- 正式 Release ZIP 在仓库外独立解压，**4,414 个文件**完成完整性与包结构检查，实际发布 EXE 的 **28 项原生集成检查通过**，覆盖 11 个页面及原有播放、主题、导航、窗口和托盘行为。
- 列表检查覆盖六类歌曲表格、圆角与尺寸、选中／悬停状态、原生多选及 160 行滚动复用。歌词检查覆盖进度、暂停、回退、换行和长句折行；回退到起点的原生渲染与初始状态一致。
- 正式安装 EXE 在临时目录完成安装、同版本覆盖升级、全部运行文件校验、安装后独立 EXE 的 28 项检查和卸载；个人资料库配置保持不变。
- 上下渐隐已检查实时合成画刷连接与视口尺寸；`RenderTargetBitmap` 无法捕获该 Composition 遮罩，**渐隐观感和高刷新率下的动态帧率尚未人工验收**。
- 本次没有修改音频解码或下载后端，也没有重新验收真实 Apple 账号、DAC 独占输出或原生 DSD／DoP。自动检查不代表所有硬件、在线服务或编码变体均已验证。

安装器构建脚本位于 `desktop/winui/build_installer.py` 和 `desktop/winui/installer/AMDownloader.iss`；对应应用源码和许可证随运行包提供。安装器使用 [Inno Setup](https://jrsoftware.org/isinfo.php)。完整功能与播放规格见 [项目 README](https://github.com/Lauk1z/AM-Downloader/tree/v2.0.0-preview.3#readme)，原生重构内容见 [preview.1 大升级说明](https://github.com/Lauk1z/AM-Downloader/releases/tag/v2.0.0-preview.1)。
